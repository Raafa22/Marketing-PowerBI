# Marketing-PowerBI
Projeto Acadêmico: BI de Vendas e Análise do Perfil do Cliente
Projeto acadêmico de Business Intelligence desenvolvido em Microsoft Power BI, com foco na análise estratégica de vendas e no comportamento dos consumidores para orientar campanhas de marketing.

O projeto está sendo desenvolvido de forma incremental, com novas análises demográficas, geográficas e de vendas sendo adicionadas a cada entrega acadêmica.

Objetivo do Projeto
Transformar dados brutos de vendas e cadastro de clientes em painéis visuais interativos. O objetivo é analisar o perfil dos consumidores (como estado civil, gênero e hábitos de consumo) e a performance geográfica das vendas (identificando os países e regiões com maior volume de conversão), fornecendo insights estratégicos para direcionar a campanha de marketing ao público-alvo correto.

Principais Indicadores e Visões da Análise
Perfil Demográfico do Consumidor: Segmentação dos clientes por estado civil (casados vs. solteiros), gênero e perfil para entender quem são os principais compradores.

Análise Geográfica de Vendas: Mapeamento de vendas por país e região, identificando os mercados com maior volume e rentabilidade.

Suporte à Campanha de Marketing: Indicadores para embasar a tomada de decisão sobre onde investir recursos de mídia e qual mensagem direcionar para cada segmento de cliente.

Tecnologias Utilizadas:Microsoft Power BI,Power Query,DAX,CSV,GitHub


Nota: Todos os dados utilizados neste projeto são inteiramente fictícios, tendo sido gerados e estruturados exclusivamente para fins acadêmicos e de demonstração prática das funcionalidades do Power BI.
